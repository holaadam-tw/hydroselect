# HydroSelect 專案規格書

## 產品定義
**名稱**: HydroSelect - 液壓系統智能選型平台
**類型**: 單頁式 Web 應用程式 (SPA)
**目標用戶**: 液壓系統工程師、設備製造商、機械設計人員
**核心價值**: 根據工況需求一鍵完成液壓系統全套元件（油壓缸、泵、電機、閥件）的選型計算與品牌推薦

## 功能模組

### 1. 輸入表單
- **應用場景快速套入**: 吹瓶機、裁斷機、彎管機預設參數，以及自定義模式
- **油壓缸參數**: 推力 (kN)、工作壓力 (MPa)、活塞速度 (mm/s)、行程 (mm)、內缸徑（選填）、定位精度
- **電機類型選擇**: 異步感應電機 / 伺服電機（含負載時間、休息時間、扭矩、功率等進階參數）
- **工況設定**: 定速連續 / 變速節能模式

### 2. 計算引擎 (`calcSystem`)
- **油壓缸計算**: 根據推力和壓力計算最小缸徑，自動向上取整至標準缸徑 (32~250mm)，計算桿徑、需求流量、工作壓力利用率
- **油壓泵計算**: 考慮容積效率 (η_v=0.92) 計算泵排量，取標準排量 (2.5~100 cc/rev)，計算輸出流量和軸功率
- **電機計算**: 考慮泵效率 (η_p=0.88) 和電機效率 (η_e=0.93) 計算電機功率，取標準功率 (0.75~55 kW)，計算負載率
- **閥件計算**: 方向閥流量（泵流量×1.2）、額定壓力（系統壓力×1.3）、溢流閥設定壓力

### 3. 結果展示
- **系統總覽列**: 缸徑、泵排量、電機功率、閥件流量、系統壓力、電機類型
- **分頁顯示**: 油壓缸 / 油壓泵 / 電機 / 閥件 / 總報告，各頁含計算結果和品牌推薦
- **品牌推薦**: 三級分類（預算型/標準型/旗艦型），涵蓋台灣、日本、美國、中國品牌
- **總報告**: 系統串聯設計流程、元件匯總表、工程注意事項

### 4. 品牌資料庫
| 元件類型 | 品牌範例 |
|---------|---------|
| 油壓缸 | SHAKO 鑫祿、Mindman 金器、Yuken 油研、Parker、華德 Huade |
| 油壓泵 | Anson 安頌、Chaite 柴特、Yuken 油研、Parker、華德 Huade |
| 電機 | 東元 TECO、台達 Delta、安川 Yaskawa、Parker、正泰 CHINT |
| 閥件 | 北部精機 Northman、全懋 CML、Yuken 油研、Parker、華德 Huade |

## 技術規格
- **框架**: React 19.2 + Create React App
- **語言**: JavaScript (ES6+)
- **樣式方案**: CSS-in-JS (inline styles)，暗色主題
- **字型**: Noto Sans TC (Google Fonts)
- **目標瀏覽器**: 現代瀏覽器（Chrome、Firefox、Safari 最新版）
- **響應式**: 基本支援（grid layout 自適應）

## 設計規範
- **色彩主題**: 暗色背景 (#080b0e)，琥珀色主色調 (#f59e0b)，藍色提示 (#38bdf8)，紫色伺服 (#818cf8)
- **語言**: 繁體中文（UI 文字）+ 英文（技術術語標注）
- **等級配色**: 預算型 (#64748b)、標準型 (#f59e0b)、旗艦型 (#818cf8)
